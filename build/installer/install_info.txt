星幻OCR

截图取字工具：按 F1 框选屏幕任意区域，文字立刻进剪贴板，并弹出一个小窗可以直接改。

本安装包内置全部识别模型（PP-OCRv6），安装后无需联网，识别全程在本机完成。
唯一的联网行为是检查 GitHub 更新，可在设置里关闭。

怎么用
1. 安装完成后，按 F1。
2. 拖拽框选要识别的区域。
3. 松手后文字已复制，结果窗口可以点「复制」或直接改。

托盘图标常驻，右键可打开设置、改快捷键、检查更新。
若 F1 与其它软件冲突，程序会提示，可在设置里换成任意按键。

完全免费，禁止售卖。
基于 PaddleOCR 的 PP-OCRv6 模型，以 GPL-3.0 开源。
